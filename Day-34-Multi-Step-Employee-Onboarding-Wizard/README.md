# Day 34 - Multi-Step Employee Onboarding Wizard

## 📌 Scenario

Build a Multi-Step Employee Onboarding Wizard using Lightning Web Components (LWC).

The wizard guides HR users through a structured employee onboarding process by dividing data entry into multiple steps.

Instead of displaying all fields on one page, users complete the onboarding process step-by-step and review all information before submission.

---

## 🚀 Business Requirements

### Step 1 - Basic Information

Capture:

* Employee Name
* Email
* Phone

---

### Step 2 - Job Information

Capture:

* Department
* Designation
* Salary

---

### Step 3 - Review Information

Display all entered information:

* Employee Name
* Email
* Phone
* Department
* Designation
* Salary

Allow the user to verify data before saving.

---

### Step 4 - Submit

Create an Employee__c record.

Display success message after record creation.

---

## 🔗 Object Used

### Employee__c

Fields:

* EmployeeName__c
* Email__c
* Phone__c
* Department__c
* Designation__c
* Salary__c

Wizards improve user experience and reduce data-entry errors.
