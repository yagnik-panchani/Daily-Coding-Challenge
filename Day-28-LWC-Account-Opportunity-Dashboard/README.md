# Day 28 - LWC Account Opportunity Dashboard

## 📌 Scenario

Build a Lightning Web Component that allows users to search for Accounts and view their related Opportunities dynamically.

The component communicates with Apex using an Imperative Call and displays both Account details and related Opportunity information in a Lightning Datatable.

---

## 🚀 Business Requirement

Users should be able to:

1. Enter an Account Name.
2. Click the "Load Details" button.
3. View matching Account information.
4. View all related Opportunities for the Account.

---

## 🔗 Object Relationship

Account → Parent Object

Opportunity → Child Object

---

✅ Search Accounts dynamically

✅ Display Account Details

✅ Display Related Opportunities
