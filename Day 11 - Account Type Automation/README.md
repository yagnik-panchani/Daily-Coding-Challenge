# Day 11 - Account Type Automation

## 📌 Scenario

Whenever the number of related Contacts under an Account becomes greater than 3:

- Automatically update Account Type = Premium Customer

---

## 🔗 Object Relationship

Account → Parent Object  
Contact → Child Object

---

## 🚀 What This Automation Does

✅ Counts related Contacts dynamically  
✅ Updates Account Type automatically  
✅ Improves customer categorization  
✅ Demonstrates Parent-to-Child relationship handling

---

## 🧠 Technical Concepts Used

- Apex Trigger
- Relationship Queries
- Aggregate Logic
- Cross-Object Update
- Bulkification

---

## 💡 Business Use Case

Businesses often categorize customers based on engagement level.

This automation helps identify:
- Premium customers
- Highly engaged Accounts
- Important customer relationships

---

## 🔥 Key Learning Outcome

Through this scenario, I learned:

- How to count related child records
- How to update parent records dynamically
- How relationship queries work in Salesforce
- How to implement business categorization logic
