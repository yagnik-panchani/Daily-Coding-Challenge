# Day 13 - Closed Won Opportunity Automation

## 📌 Scenario

Whenever an Opportunity Stage becomes Closed Won:

1. Update related Account Type = VIP Customer
2. Create follow-up Task for Account Owner
3. Update all sibling Opportunities Description

---

## 🔗 Object Relationship

Account → Parent Object  
Opportunity → Child Object  
Task → Activity

---

## 🚀 What This Automation Does

✅ Detects Opportunity stage transition  
✅ Updates customer Account automatically  
✅ Creates sales follow-up Task  
✅ Synchronizes sibling Opportunity records  
✅ Improves CRM sales workflow

---

## 🧠 Technical Concepts Used

- Apex Trigger
- Trigger.oldMap
- Parent Child Relationship
- Cross Object DML
- Task Automation
- Bulkification

---

## 💡 Business Use Case

Winning a deal usually requires:
- Customer onboarding
- Sales follow-up
- VIP customer management

This automation handles those processes automatically.
