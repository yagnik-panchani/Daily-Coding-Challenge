# Day 30 - Dynamic Leave Approval Dashboard

## 📌 Scenario

Build a Leave Management Dashboard using Lightning Web Components (LWC).

The dashboard displays employee leave requests, calculates summary statistics, and allows users to filter leave requests dynamically based on their approval status.

---

## 🚀 Business Requirement

Display four dashboard cards:

* Total Requests
* Approved Requests
* Pending Requests
* Rejected Requests

Display employee leave records in a datatable.

Provide a filter dropdown with:

* All
* Approved
* Pending
* Rejected

When a user selects a status, only matching records should be displayed.

---

## 🔗 Object Used

Employee__c

Fields:

* EmployeeName__c
* LeaveType__c
* Status__c
